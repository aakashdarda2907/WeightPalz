Install as an app

Add WeightPalz to your home screen to check in with one tap.

You're using the installed app ✓

iPhone and iPad
  1. Open this site in Safari.
  2. Tap the Share button (the square with an arrow).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top right corner.
Android · Chrome
  1. Tap the menu button (three dots) at the top right.
  2. Tap Install app or Add to Home screen.
  3. Tap Install to confirm.
Samsung Internet
  1. Tap the menu button (three lines) at the bottom right.
  2. Tap Add page to, then Home screen.
  3. Tap Add to confirm.
Android · Firefox
  1. Tap the menu button (three dots).
  2. Tap Install.
  3. Tap Add to confirm.
Computer
  1. Chrome or Edge: click the install icon at the right end of the address bar, then Install.
  2. Safari on Mac: choose File, then Add to Dock.
  3. Firefox: it can't install web apps on computers. Use Chrome or Edge.
